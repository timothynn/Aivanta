# Veyntis — Website design system

Veyntis is an independent applied AI and systems engineering studio. We integrate intelligence into existing applications, documents, data and business workflows. The brand must feel competent, focused, architectural and trustworthy.

## Identity
- Name: **VEYNTIS**
- Positioning: **Applied AI & Systems Engineering**
- Signature: **Intelligence, engineered into your operations.**
- Hero: **Your systems already work. Make them work smarter.**
- Tone: direct, measured, technical without jargon
- Never imply unverified customers, results or regulatory approvals

## Visual tokens
- Obsidian: `#091218`
- Forest graphite: `#11251f`
- Emerald: `#75ddb8`
- Paper: `#eff3ee`
- Slate sage: `#667b71`
- Type: Manrope (headlines), DM Sans (body), monospace for system labels

Use a sharp geometric V symbol (not a literal wolf). Subtle systems-flow motifs, restrained lines, no robots or neon brains. Respect reduced-motion preferences.

## Homepage
1. Clear hero + single high-intent project CTA
2. Three solutions: AI Integration, Workflow Intelligence, Knowledge Systems
3. Interactive existing-system transformation demo
4. Discover / Prove / Scale engagement pathways
5. Trust and engineering standards
6. Domain perspective: aviation, finance, logistics, professional services, enterprise software
7. Four-step opportunity assessment
8. Contact + privacy/AI notice

## Experience quality
- Native-feeling interaction, fast load, semantic landmarks
- Excellent mobile navigation and keyboard focus
- Honest illustrative examples clearly distinguished from client work
- Preserve analytics and existing backend API contracts
- No employer/client names or confidential implementation specifics
