# Aivanta Website UI Design Prompt

Design a polished, modern B2B technology consultancy website for **Aivanta**, an AI software consultancy that helps companies turn existing software into intelligent, AI-enabled applications.

## Brand
- Name: Aivanta
- Tagline: **Turn software into intelligent software.**
- Positioning: practical AI transformation for existing business applications
- Audience: founders, CTOs, product leaders, operations leaders, and organizations with established software, data, documents, and workflows

## Core message
Aivanta does not sell generic chatbots. It helps businesses add useful AI capabilities to the software they already depend on: AI assistants, knowledge retrieval, document intelligence, workflow assistance, agentic task execution, and AI modernization.

## Visual direction
Create a premium enterprise technology aesthetic: calm, credible, intelligent, minimal, and human. Avoid the visual clichés of AI marketing such as robot heads, glowing brains, excessive neon, stock futuristic circuitry, or overly dark cyberpunk layouts.

Use the supplied Aivanta logo concept as the primary brand reference. Preserve the logo's abstract A-shaped mark, orbit/ribbon motion, and blue-cyan-teal energy.

## Color system
- Primary navy: #0A1F44
- Blue accent: #2563EB
- Cyan accent: #06B6D4
- Teal accent: #14B8A6
- Pale blue: #E0F2FE
- Slate: #94A3B8
- White backgrounds with restrained dark sections

Use gradients sparingly for emphasis. Keep most surfaces neutral and highly readable.

## Typography
Use a modern, highly legible sans-serif such as Inter or a similar contemporary grotesk. Strong hierarchy, generous line height, restrained letter spacing, and short paragraphs.

## Homepage structure
1. **Navigation**
   - Aivanta logo
   - Services
   - Approach
   - Industries
   - About
   - Contact
   - Primary CTA: **Start a conversation**

2. **Hero**
   - Eyebrow: AI SOFTWARE CONSULTANCY
   - Headline: **Turn software into intelligent software.**
   - Supporting text: Aivanta helps businesses integrate AI into the applications, data, documents, and workflows they already rely on.
   - Primary CTA: **Explore AI transformation**
   - Secondary CTA: **See how it works**
   - Include a subtle visual showing a traditional application becoming an AI-enabled application.

3. **Problem / opportunity**
   - Many businesses already have valuable software and data.
   - The opportunity is to add intelligence rather than replace everything.
   - Present this as a simple transformation story: Existing software → AI layer → Intelligent workflows.

4. **Services**
   Create five clean service cards:
   - AI Application Assessment
   - AI Integration
   - Agentic Workflows
   - Document & Knowledge Intelligence
   - AI Modernization

5. **How Aivanta works**
   Show a six-step process:
   Discover → Identify → Integrate → Validate → Deploy → Improve

6. **Transformation visual**
   Compare a traditional application with an intelligent application. Show connections from UI/API to data, documents, workflows, and AI capabilities.

7. **Industries**
   Highlight complex and regulated environments without limiting Aivanta to one vertical:
   - Aviation
   - Professional Services
   - Financial Services
   - Logistics
   - Enterprise Software

8. **Why Aivanta**
   Focus on practical engineering rather than hype:
   - Works with existing systems
   - Domain-aware
   - Secure and responsible
   - Human-centered
   - Built for real workflows

9. **Final CTA**
   Headline: **Your software already works. Let's make it intelligent.**
   CTA: **Start a conversation**

10. **Footer**
   Simple, professional footer with logo, short description, navigation, social/GitHub links, and legal placeholders.

## Interaction and motion
Use subtle motion only:
- Logo mark gently animates on page load
- Cards rise/fade into view
- Transformation diagram has restrained flow animation
- Buttons have small hover transitions
- Avoid distracting continuous animations

## Responsive behavior
Design desktop-first but fully responsive. The experience must feel deliberate on laptop, tablet, and mobile. Navigation should collapse cleanly, cards should stack naturally, and the hero should remain readable without excessive vertical space.

## Accessibility
Use strong color contrast, semantic hierarchy, visible focus states, keyboard-friendly controls, reduced-motion support, and descriptive labels.

## Overall feeling
The finished website should feel like a small, credible, technically sophisticated consulting firm — not a flashy AI startup landing page. Think **enterprise-grade software consultancy + modern applied AI**.
