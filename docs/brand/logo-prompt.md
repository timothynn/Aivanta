# Aivanta Logo Generation Prompt

## Primary prompt

Design a premium, minimal, modern logo for **Aivanta**, an engineering-led AI software consultancy that helps businesses turn existing applications into intelligent, AI-enabled systems.

The brand should communicate **intelligence, software engineering, transformation, trust, clarity, and forward movement** without relying on obvious AI clichés.

Create a distinctive abstract symbol that subtly suggests the transformation of a traditional software system into an intelligent connected system. Consider a refined geometric mark built from connected forms, an abstract upward/forward motion, or a clever negative-space relationship between an **A** and a network/system motif.

The symbol should feel precise and engineered rather than playful. It must work at favicon size, app-icon size, website header size, presentation cover size, and business-card size.

### Visual style

- Minimal
- Premium
- Enterprise-grade
- Geometric
- Clean
- Timeless rather than trendy
- Strong silhouette
- Excellent negative space
- Balanced proportions
- Subtle sense of intelligence and connectivity

### Color direction

Start with a **monochrome black/white version** first so the mark works without color.

Then create a restrained color system suitable for an enterprise technology consultancy: deep charcoal or near-black as the primary neutral, with one sophisticated accent such as muted blue, blue-violet, or teal. Avoid neon colors and excessive gradients.

### Typography

Use a clean modern sans-serif wordmark for **Aivanta**. The lettering should feel confident, technical, refined, and approachable.

Avoid futuristic sci-fi fonts, overly rounded startup fonts, or decorative typography.

### Composition

Generate:

1. Horizontal logo: symbol + Aivanta wordmark
2. Symbol-only mark
3. Wordmark-only version
4. Light-background version
5. Dark-background version
6. Monochrome version

### Brand feeling

The finished identity should feel appropriate beside brands in enterprise software, technology consulting, cloud infrastructure, and professional services.

It should suggest:

**Traditional software → intelligent software**

without literally depicting a robot, brain, chip, chatbot, circuit board, or glowing AI head.

### Avoid

- Robot heads
- Brain icons
- Chat bubbles as the primary symbol
- Generic circuit-board icons
- Generic infinity symbols
- Excessive nodes and connections
- Neon cyberpunk aesthetics
- Cryptocurrency aesthetics
- Overly complex marks
- Stock-logo appearance

Produce a highly polished professional identity suitable for a real technology consultancy named **Aivanta**.
